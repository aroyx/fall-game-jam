##### Controls

| Controls | Action |
| :--- | :--- |
| WASD/Arrow Keys | Movement |
| Space/Enter | Jump |
| Shift/C | Sprint |
| Right Click/X | Interact |
| R | Respawn |

### Cozy Fall Jam 2026

This game was made for the [Cozy Fall Jam 2026](https://itch.io/jam/cozy-fall-jam-2026) a 3 day game jam with theme "roots". I had big plans and small skills. This being my first 3D game didn't help either. I wasn't able to achieve my goals. But! I did have way too much fun doing other things like making the models, music and the camera system xD (tho the camera can be annoying a lil) and that killed a lot of my time.

Anyway, this was my take on "Cozy Fall Jam 2026" hope you like it :)
